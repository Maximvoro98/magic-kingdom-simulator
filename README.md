# Eldoria — The Living Kingdom

A playable browser-based 3D fantasy-industrial civilization simulator.

**Current release:** v0.2.1 · **Website:** https://maximvoro98.github.io/magic-kingdom-simulator/

## Play
Open [the game](https://maximvoro98.github.io/magic-kingdom-simulator/) or open `index.html` locally.

## Game systems
- 3D village exploration and building selection
- Individually recorded residents, homes, jobs, health, happiness, and magical traits
- Annual turns, royal decisions, resources, and organic population change
- Ministry reports grounded in the deterministic simulation
- Browser-local saved games

The public static site does **not** include AI-powered briefings; those require a separate secure backend. Never put API keys in frontend code.

## Development
The current published `index.html` is a self-contained generated build. The complete modular source project with tests is available in the project archive from the development conversation and should be synchronized in a subsequent source import. The site publishes automatically using `.github/workflows/deploy.yml` on pushes to `main`.
